# Quickstart: проверка удаления последнего номера

Все команды — в контейнере `app` (`Makefile`).

## 1. Автоматические проверки

```bash
make test   # все четыре suite, включая Concurrency
```

Нужны зелёными:
- `tests/Feature/Admin/Web/WithdrawIdentifierTest.php` — хвост, откат счётчика, повтор темы, отказ из
  середины, устаревшая страница, 404, 403, статус пары, след;
- `tests/Feature/Sequence/WithdrawTest.php` — домен без HTTP;
- `tests/Feature/Models/IdentifierImmutabilityTest.php` — `delete()` и остальные записи всё ещё бросают;
- `tests/Concurrency/ConcurrentWithdrawTest.php` — снятие против выдачи (research.md R7).

## 2. Руками в консоли (SC-001)

1. Пара `spec` с начальным номером 31. Выдать через MCP две темы — получатся 032 и 033.
2. `/admin/projects/{id}` → «Выданные номера»: крестик только у 033.
3. Крестик → подтвердить. Flash «Номер «033-…» удалён. Следующий номер — 33.», крестик переехал к 032.
4. Удалить 032. «Номеров не выдано», в блоке типов «Последний выданный» 0, «Следующий» 32.
5. Снова запросить номер с темой второго шага → 032 и `is_new: true`.

## 3. Отказ из середины (SC-002)

1. Выдать 3 номера, открыть карточку в двух вкладках.
2. Во второй вкладке удалить последний, затем в первой нажать крестик у того же номера → 404.
3. Выдать ещё один номер; в первой вкладке (крестик у устаревшего хвоста) удалить → ошибка
   «Удалить можно только последний номер пары: сейчас это …», ничего не удалено.
